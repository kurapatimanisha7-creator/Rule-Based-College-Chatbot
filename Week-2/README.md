# Week 2 - Rule-Based Chatbot Development

**Rule-Based College Chatbot**

---

## Overview

During Week 2, the main focus was to develop a Rule-Based College Chatbot using the cleaned FAQ dataset prepared during Week 1.

The chatbot was developed using Python and Pandas. It uses exact question matching and keyword-based rules to identify user queries and provide predefined answers.

The chatbot was also tested using 100 questions to evaluate its category classification performance.

---

## Objective

- Load the cleaned College FAQ dataset.
- Preprocess user questions.
- Implement exact question matching.
- Implement keyword-based category matching.
- Generate predefined chatbot responses.
- Handle unknown questions using a fallback response.
- Create an interactive chatbot.
- Test the chatbot using 100 questions.
- Calculate category classification accuracy.
- Save the chatbot test results.
