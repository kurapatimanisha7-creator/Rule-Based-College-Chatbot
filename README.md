# 🎓 Rule-Based College Chatbot

A Rule-Based College Chatbot developed as part of my **EDP Internship**. This project helps students by answering frequently asked college-related questions such as admissions, courses, fees, hostel, library, placements, examinations, scholarships, and campus facilities.

</div>

---

# 📖 About the Project

The Rule-Based College Chatbot is designed to provide quick and accurate responses to common college queries using predefined rules and a custom FAQ dataset.

The project is developed in a structured, week-by-week approach. Each week focuses on a different stage of development, including dataset preparation, chatbot implementation, testing, and documentation.

---


## 📈 Project Evolution

| Week | Main Topic | Main Outcome |update|
|------|------------|--------------|----------|
