# Linear Regression

This folder contains the Linear Regression Machine Learning task completed during Week 2.

## Objective

To build a Linear Regression model for predicting student marks based on study hours.

## Files

- `linear_regression.ipynb` - Jupyter Notebook containing the model implementation.
- `student_marks.csv` - Dataset used for training and testing.

## Techniques Used

- Data preprocessing
- Train-test split
- Linear Regression
- Prediction
- MAE
- MSE
- RMSE
- R² Score
- Data visualization
