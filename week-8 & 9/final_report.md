# Final Report – College Rule-Based Chatbot

## 1. Project Title

College Rule-Based Chatbot

## 2. Project Objective

The main objective of this project is to develop a chatbot
that can answer common college-related questions using a
college FAQ dataset.

## 3. Project Description

The College Rule-Based Chatbot accepts questions from users
and provides relevant answers from the college FAQ dataset.

The project was developed step by step by performing data
cleaning, chatbot development, text processing, TF-IDF based
feature extraction, intent classification, conversation
handling, edge-case handling and final testing.

## 10. Limitations

- The chatbot depends on the available FAQ dataset.
- It may not answer questions that are outside the dataset.
- Complex conversations may not always be handled correctly.
- The current version uses a console-based interface.
