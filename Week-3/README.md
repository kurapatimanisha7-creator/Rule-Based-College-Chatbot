## Overview

During Week 3, the Rule-Based College Chatbot was improved by introducing Natural Language Processing and Machine Learning techniques.

The main focus was to classify college-related questions using TF-IDF and a Multinomial Naive Bayes classifier.

## Objective

- Apply NLP techniques to chatbot questions.
- Convert text into numerical features using TF-IDF.
- Train a Machine Learning classification model.
- Predict college FAQ categories.
- Connect predicted categories with FAQ answers.
- Compare the ML-based approach with the Week 2 rule-based chatbot.
